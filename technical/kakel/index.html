kakel

the windowing layer

kakel puts more than one thing on the screen at once. it divides punkt's full-screen console into a tiled grid of up to four windows, each with its own skalman session.

layout

boot starts with one full-screen window above a one-row status bar. each split adds a window, up to a 2×2 grid. close removes the focused one. the status bar at the bottom shows uptime, disk and memory use, with a meter that turns amber and then red as the disk or memory fills. it also shows the day, the date and the time, as utc plus the offset set with zone and saved in tid.zone in the root.

a graphical program's window has a title strip with the program's name and the window's number. at its right end are two boxes. [+] fills the screen and turns into [-], which gives it back. [x] closes the window, the same as alt-w.

alt-m makes the focused window fill the screen. alt-m again puts every window back where it was. the others keep running behind it, but draw nothing until they are shown again. alt-tab while a window fills the screen brings the next one up in its place. opening or closing a window goes back to the usual layout.

focus

keyboard input goes to the window with focus. alt-tab moves focus through the windows in reading order. a left click gives focus to the window under the pointer. that click does only that, so the first click on a browser does not follow a link. the next click belongs to the program.

a program cannot move the keyboard focus away from a window it does not own. when the folder a window is working in is removed, the window goes back to / and says so.

tavla

a graphical ring-3 program gets a tavla, an ordinary tile with a one-row title strip the program cannot draw over. the strip names the program, is bright when the window has focus and dim when it does not. it offers the way out, alt-w closes the tavla and stops the program. a program can ask for alt-w as a key instead, as skrift, pensel and form do, so they can save or ask first. one that asks and then stops listening is stopped by the next alt-w a second later. while a tavla has focus every key goes to its program, except alt-w, alt-m and alt-tab, so a tavla can always be left or closed.

when the layout changes, a program in a tavla finds out through win_info() and redraws its own window. every ring-3 program started with start gets a window of its own. whatever it prints lands there.

the screen saver

dvala draws a field of stars when the machine has been idle. it is off at boot. dvala on waits five minutes, dvala 90 waits ninety seconds and dvala off turns it off. dvala alone says the wait in seconds. a key press ends it.
